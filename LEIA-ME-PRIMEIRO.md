# Pedidos Resilientes — Marcos Solutions

Demonstração de consulta de pedidos com React e TypeScript. API simulada e dados fictícios.

1. Instale o Node.js 24 e extraia este ZIP.
2. Abra o terminal na pasta pedidos-resilientes.
3. Execute `npm ci` e depois `npm run dev`.
4. Abra http://127.0.0.1:5173.
5. Consulte com Sucesso; selecione HTTP 503 e atualize; observe os dados preservados; volte a Sucesso e tente novamente.

Arquivos para apresentação:
- media/desktop.png e media/mobile.png: capturas reais.
- media/demo.mp4: vídeo real de 16,6 segundos, H.264, sem áudio.
- docs/LINKEDIN.md: texto sugerido para revisar e publicar manualmente.
- docs/ROTEIRO-5-DIAS.md: estudo, entrevista e preparação do GitHub.
- docs/VALIDATION.md e logs: resultados e limitações da validação.
- README.md: documentação técnica em inglês.

Verificação realizada: build aprovado, 13 testes unitários e 6 testes no Chromium aprovados. Leitor de tela, outros navegadores e integração com API real permanecem pendentes. Nada foi publicado automaticamente.
